# Visible action review

2026-10-24. Baseline: frozen UX-reset source and captured live audit; no Claim
button existed in that build. Ordinary nodes were already automatic. The actual
chores were discovery/trial pauses, duplicate navigation and fragmented object
management. Runtime button inventory is written to `VISIBLE_ACTIONS.json` by
the new Living UI capture script; historical browser screenshots are retained.

| Action family | Purpose | Implementation decision |
|---|---|---|
| Cultivate / Explore / Build | Navigate | Retain three stable destinations |
| View route → preview → Depart | Select then commit | Select the named route directly in the preparation composition; one pinned Depart |
| Back to routes / duplicate subsection links | Navigate | Remove redundant return to the same selection; keep region/route selectors together |
| Camp / Continue | Decide safe pause / resume authorization | Retain; discovery and ordinary multistage transitions no longer demand Continue |
| Discovered art / ordinary reward | Acknowledge | Credit once and show a nonblocking strip; keep the discovery in Build |
| Technique Equip / Improve / global Details | Choose object / spend / inspect | One illustrated object row opens one sheet with effect, exact free slot target and distinct improvement purchase |
| Gear Compare / Refine / refinement-detail link | Compare / spend | One item sheet contains current comparison, free equip and actual refinement outcome/price |
| Clear | Remove selection | No global Clear; explicit Remove from slot on the selected object |
| Reorder | Build decision | Keep Earlier/Later inside the equipped object's management context |
| Learned / all collection filter | Inspect acquisition | Keep one collection/filter affordance; no global duplicated technique-details page |
| Preset Save / Apply | Save / replace build | One preset context covering method, ordered arts, gear and law; restore is free and omissions are explicit |
| Optional preparation / advancement | Spend deliberately | Keep exact price/effect and one explicit commitment; never an animation callback |
| Offline summary Return | Acknowledge | Replace routine modal with a compact nonblocking earned-yield strip |
| Mastered supply assignment | Authorize solved work | Explicit three-circuit assignment in route inspection; no repeated Claim/Depart; stop requests camp |
| Menu / sound / display / help / credits | Settings / explain | Preserve in Menu; no permanent settings on the gameplay surface |

The object sheet may expose several slot targets because each is a real build
choice. That is distinct from duplicating global buttons around every object.
Costs remain visible before purchase. Free Equip never buys mastery/refinement.
